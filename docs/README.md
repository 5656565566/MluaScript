## 项目简介

MluaScript 是一个结合了 Python 后端运行环境、MaaFramework 自动化能力、以及 Web (Blockly 可视化编程) 和 TUI 前端的脚本执行平台

## 文档规划

随着项目的不断完善，本目录预计将包含以下类型的文档：

- **快速入门**: 项目的安装、配置和运行指南。
- **架构设计**: 核心模块 (如 Runtime, Control, Maa 封装等) 的设计理念和交互流程。
- **Lua API 手册**: 供脚本开发者使用的内置 Lua 函数和 Maa 相关 API 说明。
- **界面使用指南**: Web 界面和终端 TUI 界面的详细操作说明。
- **开发与贡献**: 开发环境搭建、代码规范和测试运行指南。

> **提示**：目前文档库仍在建设中，更多详细内容将陆续补充。
